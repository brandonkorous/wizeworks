# 3. The WizeWorks Maker's Mark

The WizeWorks symbol is a **maker's mark**, not a lettermark.

It does not contain a W or WW.

The mark is built from a repeated geometric unit arranged around a central negative-space opening.

## Core Concept

> **One shape. Repeated. Three visible. One implied.**

The repeated form represents a consistent foundation used to create different outcomes.

The open center represents:

- possibility
- creation
- room for what comes next
- the space where individual parts become a system

The mark should feel equally appropriate:

- on a website
- stamped into metal
- debossed into leather
- embroidered on workwear
- embossed into paper
- applied to a building
- placed beside a product logo

# 4. Logo Geometry

## Canonical Rule

The currently approved WizeWorks icon geometry is **locked**.

Do not:

- redraw the individual pieces
- alter the corner rounding
- sharpen the corners
- soften the corners
- change the internal notch
- change the spacing between pieces
- stretch the icon
- compress the icon
- rotate individual pieces independently
- make each component a different shape
- introduce additional geometry into the center
- turn the mark into a W
- place a W inside the mark

The exact approved source artwork should be used whenever production assets are created.

The visual strength of the mark comes from its precise proportion and repeated geometry.

# 11. Typography Scale

**The scale is a closed set. There are no custom font sizes.**

Every size in the system is one of these named steps. No `clamp()` written by
hand, no arbitrary pixel values, no computed or inline `font-size`.

| Step | Size | Use |
|---|---|---|
| `display-1` | 40 → 72px | The hero statement. One per page. |
| `display-2` | 34 → 60px | Major section statements. |
| `display-3` | 30 → 48px | Standard section headings. |
| `2xl` | 24px | Sub-headings, feature card titles. |
| `xl` | 20px | Card titles, principle titles. |
| `lg` | 18px | Supporting copy under a heading. |
| `md` | **16px** | **Body. The default.** |
| `sm` | 14px | Secondary labels, captions, metadata. |

## 16px is the floor

`sm` (14px) is the smallest step that exists, and it is for genuinely secondary
text only. **Anything below 14px is banned outright** — no 13px, no 12px, no
11px, no 10px.

The reason is not taste. 16px is the size the largest number of people can read
without effort, and WizeWorks builds for people doing real work — founders,
farmers, operators, service businesses — on whatever device and in whatever
light they happen to be in. A page that is hard to read does not get used, and a
product nobody can read is not a product that works.

This rule outranks any layout that would be tidier with smaller text. If a
label does not fit at 14px, the label is too long or the layout is wrong.

## Component sizes carry their own font sizes

The rule applies to what actually renders, not just to what the markup says.
Silica's own size props set font sizes internally, and the small end of every
ramp sits under the floor. Buttons, for example:

| Prop | Font size | Allowed |
|---|---|---|
| `size="xs"` | 11px | no |
| `size="sm"` | 12px | no |
| `size="md"` (default) | 14px | secondary actions only |
| `size="lg"` | 16px | **the default for anything primary** |

A grep of the source cannot catch this — the size is in the library's CSS. It
has to be measured in the browser. The header CTA shipped at 12px for exactly
this reason and was only caught by reading computed styles off the rendered
page.

Use generous line height and restrained letter spacing.

# 12a. Density Is Spacing, Not Type Size

**Density is how close things are to each other. It has nothing to do with how
big the text is.**

This distinction matters because the instinctive fix for a cramped layout is to
shrink the type, and that fix is backwards. Smaller text does not make a layout
less dense — the elements are still just as close together, and now they are
also harder to read. It makes both problems worse at once and calls it a
solution.

## When something feels cramped

Reach for space, never for a smaller step on the type scale:

- increase padding inside the container
- increase the gap between siblings
- increase margin between groups
- open up line-height
- narrow the measure so lines break sooner
- remove an element
- split the section in two

## Bigger type needs more room, not less

Raising a font size without raising the space around it *increases* density. A
24px heading in a box sized for 18px is tighter than it was before, even though
nothing moved. Whenever a type size goes up, the padding, gap, and margins
around it go up with it.

## The rule

> If it feels crowded, add space.
> If it is hard to read, add space.
> Never take space away from the reader by taking size away from the type.

The 16px floor (§11) and this section are the same idea from two directions:
the reader gets room, both inside the words and around them.

# 22. Image Direction

Photography should feel:

- real
- dimensional
- tactile
- architectural
- human
- precise

Good subjects:

- people building
- sketches
- prototypes
- workshops
- hardware
- product interfaces
- packaging
- materials
- real businesses
- tools
- physical spaces

Avoid generic corporate stock photography.

Avoid exaggerated futuristic AI imagery.

## What "avoid stock" does and does not mean

The ban is on a **genre**, not on a sourcing method. Boardroom handshakes,
headset call-centre smiles, and hands-on-a-laptop filler are out no matter where
they came from — including a shoot we paid for ourselves.

Open-licensed photography that shows the subjects listed above is not only
allowed, it is the practical way to get real imagery without waiting on a
photographer. Prefer **CC0 / public domain**, which needs no attribution and
carries no share-alike obligation. Record what was used and where it came from
(see `site/public/photos/CREDITS.md`).

Two rules when sourcing:

1. **Look at the file before using it.** Metadata lies. A candidate rejected
   during the homepage build was labelled CC0 and arrived with a repeating
   watermark burnt across the frame.
2. **Judge it against the subject list, not the search term.** A photograph that
   merely matched the query but reads as corporate filler is still corporate
   filler.
